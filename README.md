# Smart Computer Solutions - Support Helpdesk Pro

A custom PHP-based helpdesk and ticketing plugin built to streamline technical support, client inquiries, and system administration for [Smart Computer Solutions](https://smartcomputer.co.za).

## 🏢 About Smart Computer Solutions
Founded in 1999, Smart Computer Solutions is a leading South African provider of mining training software, enterprise Learning Management Systems (LMS), and HRD management platforms. They specialise in compliance-driven training technology for the mining, industrial, and enterprise sectors. 

Their flagship product, the **CTS Platform**, provides end-to-end HRD management, computer-based training (CBT), and mobile assessments for high-risk operational environments.

## 🎯 Purpose of This Plugin
This FreshDesk-style helpdesk application is designed to act as the support backbone for Smart Computer Solutions. It allows their technical team to:
*   Manage support tickets from mining and enterprise clients.
*   Track issues related to the CTS Platform, SmartClick, and CTS Mobile.
*   Provide a clean, intuitive interface for support agents to resolve technical and software inquiries efficiently.
